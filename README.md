# Iris-Data-Analysis-by-Using-PowerBI

Unlocking Insights from Iris Data Analysis 🔓

I recently dove into the Iris dataset and uncovered some fascinating findings:

🌟 Key Insights:

- Setosa species are distinct in both sepal and petal measurements 🌿
- Petal length and width provide clearer separation between species compared to sepal measurements 💡
- Versicolor and Virginica show overlap, but Virginica tends to have larger petals 📈

📊 KPIs:

- Average length and width values of all species
- Total number of items: 150


📈 Visualizations:

- Scatter plots for sepal length vs. width and petal length vs. width, highlighting the differences between Setosa, Versicolor, and Virginica 📊
- * Top 3 length and width values for all species and individual species 🏆
